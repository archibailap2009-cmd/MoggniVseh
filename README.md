## Публикация на GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / root. Сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

## Деплой на Vercel (бэкенд + сайт)
1. vercel.com → войти через GitHub → Add New → Project → выбрать репозиторий.
2. Settings → Environment Variables: `ANTHROPIC_API_KEY` (ключ из console.anthropic.com) и `ANALYSIS_ENABLED=true`. Затем Redeploy.
3. Выключить анализ мгновенно: поменять `ANALYSIS_ENABLED` на `false` и сделать Redeploy.
Ключ никогда не коммитим в репозиторий (`.env` в `.gitignore`).
